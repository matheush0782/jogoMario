# Jogo Mario

## Descrição
O **Jogo Mario** é uma aplicação web desenvolvida no estilo *endless runner* em 2D baseada no clássico jogo do Super Mario. No jogo, o jogador controla o personagem Mario, que deve pular sobre os tubos que se movem continuamente pelo cenário. 

O jogo conta com:
- Animações fluidas em CSS (nuvens, movimento do tubo e pulo do personagem);
- Detecção contínua de colisões em JavaScript;
- Sistema de pontuação com incremento progressivo a cada obstáculo superado;
- Persistência de recorde (*Maior Pontuação*) no navegador via `localStorage`;
- Efeitos visuais e tela de *Game Over* com reinício rápido via teclado.

## Instalação e Execução

O jogo foi desenvolvido com tecnologias web nativas (HTML5, CSS3 e JavaScript), portanto **não requer instalação de dependências** ou gerenciadores de pacotes.

Para executar o jogo:

1. Faça o download ou clone a pasta `frontend/` do repositório.
2. Acesse a pasta `frontend/`.
3. Abra o arquivo `index.html` em qualquer navegador web (basta dar um duplo clique no arquivo ou clicar com o botão direito e selecionar **"Abrir com"**).

## Tecnologias
- **HTML5:** Estruturação dos elementos do cenário, pontuação e personagem.
- **CSS3:** Estilização visual, layout, posicionamento absoluto e animações com `@keyframes`.
- **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM, detecção de colisões, controle de fluxo e armazenamento com Web Storage API.
- **Git & GitHub:** Controle de versões, gestão de branches e colaboração em equipe.
